1. Περιγραφή
Η εφαρμογή υλοποιεί ένα σύστημα διαχείρησης των τιμολογίων και παραγγελιών ενός καταστήματος Supermarket

Bασικός σκοπός του συστήματος είναι:
-Η καταχώρηση τιμολογιών παραλαβής προϊόντων και η ενημέρωση αποθέματος 
-Η καταχώρηση νέας παραγγελίας προϊόντων 

Βασικοί χρήστες (ρόλοι)
-Υπάλληλος γραφείου (καταχώρηση τιμολογιών)
-Διευθυντής καταστήματος (καταχώρηση παραγγελιών)

Use Cases που υλοποιούνται
-Καταχώρηση τιμολογίου, περιλαμβάνει την ενημέρωση αποθέματος
-Καταχώρησης νέας παραγγελίας μετά από αποδοχή ή τροποποίηση των προτεινόμενων παραγγελιών από το σύστημα

8. Γνωστά Περιοριστικά Σημεία / Μελλοντική Επέκταση

Το σύστημα δεν υποστηρίζει τις παρακάτω λειτουργίες:
1. Μόνιμη αποθήκευση, καθώς όταν σταματήσεις το πρόγραμμα, δεν έχει κρατήσει τα δεδομένα που έχουν εισαχθεί. Αυτό συμβαίνει, επειδή δεν υπάρχει σύνδεση σε βάση δεδομένων.
2. Δεν γίνεται έλεγχος στην Καταχώρηση τιμολογίου για την εγκυρότητα της ημερομηνίας. Στην εισαγωγή στοιχείων δεν γίνεται έλεγχος για γράμματα/αριθμούς.
3. Στην εισαγωγή τιμής, αν ο χρήστης δεν εισάγει αριθμούς, το σύστημα "σκάει" και τερματίζει.
4. Μπορεί να καταχωρηθεί αρνητική τιμή στην εισαγωγή ποσότητας στην νέα παραγγελία, δεν υπάρχει περιορισμός για μη εισαγωγή αρνητικών τιμών.
5. Αν καταχωρήσεις ένα τιμολόγιο με ένα barcode, το σύστημα δεν ελέγχει αν το όνομα ή η κατηγορία συμφωνεί με αυτό που είχε καταχωρηθεί την προηγούμενη φορά για το ίδιο barcode.
6. Δεν μπορείς να αναζητήσεις ένα συγκεκριμένο τιμολόγιο ανά ID ή ένα προϊόν ανά όνομα (πρέπει να δεις όλη τη λίστα).
7. Το σύστημα προτείνει παραγγελία μόνο αν το ζητήσεις (επιλογή 4), δεν βγάζει αυτόματη ειδοποίηση όταν ένα προϊόν πέφτει κάτω από την ελάχιστη επιθυμητή ποσότητα κατά τη διάρκεια μιας πώλησης.

Σε επόμενη έκδοση θα μπορούσαμε να προσθέσουμε:
1. Αποθήκευση σε JSON/CSV και έλεγχο ημερομηνιών.
2. Μια συνάρτηση "ασφαλούς εισαγωγής". Αν ο χρήστης γράψει γράμματα στην τιμή, το σύστημα θα ενημερώνει για την λάθος μορφή, αντί να κλείνει.
3. Πριν την αποθήκευση κάθε ποσότητας, το σύστημα θα εκτελεί έναν έλεγχο αρνητικής τιμής και δεν θα επιτρέπει την εισαγωγή.
4. Δημιουργία ενός "Καταλόγου Προϊόντων". Μόλις ο χρήστης πληκτρολογεί ένα Barcode, το σύστημα θα ψάχνει αν υπάρχει ήδη. Αν υπάρχει, θα συμπληρώνει αυτόματα τα στοιχεία του προϊόντος, ώστε να μην επιτρέπει στον χρήστη να δώσει διαφορετικά στοιχεία για το ίδιο προϊόν.
5. Χρήση Λεξικών (Dictionaries) αντί για Λίστες. Προσθήκη μια επιλογής στο μενού "Αναζήτηση Προϊόντος". Ο χρήστης θα δίνει το Barcode και το σύστημα θα επιστρέφει μόνο τη συγκεκριμένη εγγραφή, αντί για όλη τη λίστα.
6. Αυτόματες ειδοποιήσεις μέσα στη συνάρτηση ενημέρωσης αποθέματος. Κάθε φορά που αφαιρείται ποσότητα ενός προϊόντος (π.χ. σε μια πώληση), η συνάρτηση θα ελέγχει αν η ποσότητα είναι λιγότερη από την ελάχιστη επιθυμητή και θα ενημερώνει τον χρήστη.
