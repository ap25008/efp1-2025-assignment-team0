Σύστημα Διαχείρισης Tιμολογίων και Παραγγελιών Supermarket
1. Περιγραφή
Η εφαρμογή υλοποιεί ένα σύστημα διαχείρησης των τιμολογίων και παραγγελιών ενός καταστήματος Supermarket

Bασικός σκοπός του συστήματος είναι:
-Η καταχώρηση τιμολογιών παραλαβής προϊόντων και η ενημέρωση αποθέματος 
-Η καταχώρηση νέας παραγγελίας προϊόντων 

Βασικοί χρήστες (ρόλοι)
-Υπάλληλος γραφείου (καταχώρηση τιμολογιών)
-Διευθυντής καταστήματος (καταχώρηση παραγγελιών)

Use Cases που υλοποιούνται
-Καταχώρηση τιμολογίου, περιλαμβάνει την ενημέρωση αποθέματος
-Καταχώρησης νέας παραγγελίας μετά από αποδοχή ή τροποποίηση των προτεινόμενων παραγγελιών από το σύστημα

5. Δομή του κώδικα
Σύντομη περιγραφή των αρχείων:

Project Supermarket/    # Ρίζα του project
.
├── main.py         # Είσοδος του προγράμματος / μενού / διάλογος με χρήστη
├── models.py       # Κλάσεις τομέα (π.χ. Product, Invoice, Order, κ.λπ.)
├── services.py     # Λογική συστήματος / συναρτήσεις χειρισμού σεναρίων
└── diagrams/
    ├── class_diagram.png
    └── sequence_diagram.png

Περιγραφή αρχείων 

main.py:
περιέχει το μενού,
διαβάζει input από τον χρήστη,
καλεί τις συναρτήσεις από services.py.

models.py:
περιέχει τις βασικές κλάσεις του συστήματος (οντότητες):
Product
Invoice
InvoiceItem
Inventory
InventoryItem
Order

services.py:
περιέχει συναρτήσεις που υλοποιούν την καταχώρηση τιμολογίου, την ενημέρωση αποθέματος και την καταχώρηση νέας παραγγελίας
